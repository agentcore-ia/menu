# NeuroRest Menu

Replica inspirada en la experiencia visual de BioMenus, adaptada para `NeuroRest`.

Incluye:

- hero visual con estilo premium para restaurantes
- buscador de platos
- filtros dieteticos
- navegacion por categorias
- cards grandes para mobile
- soporte para videos cortos dentro de los platos y en modal

## Ejecutar en local

```bash
npm install
npm run dev
```

## Build de produccion

```bash
npm run build
```

## Stack

- React 19
- Vite
- CSS custom
